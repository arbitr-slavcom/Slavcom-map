# Славком — карта оптической сети

Репозиторий веб-карты оптической сети «Славком».

Данные муфт, кабелей, сварок и делителей хранятся в Supabase и должны быть доступны только авторизованным пользователям. Не публикуйте здесь ключи service_role, пароли, выгрузки сети и личные данные.

План: GitHub Pages для интерфейса карты, защищённая Supabase Edge Function для чтения данных.
